# UVIMA Mikopo – masasisho (updates)

Folda hii ni ya **masasisho ya app** tu. Haina data ya wanachama.

- `index.html`: skrini za app (toleo jipya).
- `version.json`: namba ya toleo. App kwenye simu inaisoma kila intaneti ikiwashwa.

Kila Claude akikupa `index.html` na `version.json` mpya: pakia (Upload files) zote mbili hapa, juu ya zile za zamani, kisha bofya **Commit changes**.
